# Anamnese Fácil

Crie um site SIMPLES de ficha de anamnese online para a Personal Trainer Juliana Truglia.

O objetivo do site é APENAS permitir que as clientes preencham a ficha de anamnese e enviem as respostas pelo WhatsApp da Personal Trainer.

NÃO criar:

- login

- cadastro de usuários

- banco de dados

- painel administrativo

- sistema de pagamentos

- área da cliente

- sistema de treinos

- assinatura

- histórico de clientes

O site deve ser simples, rápido, bonito e funcionar muito bem no celular.
